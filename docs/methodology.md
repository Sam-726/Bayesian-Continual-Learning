# Methodology

## Objective

Evaluate whether approximate Bayesian sequential updating can reduce catastrophic forgetting relative to ordinary sequential fine-tuning.

## Continual-learning protocol

The model receives one Split-MNIST task at a time. After training task t, it is evaluated on all tasks observed so far.

## Baseline

A deterministic MLP is trained continuously from the previous task's weights.

## Bayesian method

Selected network weights have diagonal Gaussian variational distributions. The training objective is:

`L = NLL + beta * KL(q(w) || p(w))`

After each task, the current variational posterior is copied into the prior parameters used for the next task.

## Metrics

- final average accuracy
- average forgetting
- expected calibration error
- predictive entropy for the Bayesian model
- training time per task

All numerical results should be generated by the experiment scripts.
